# Visualization

Users can use the **Visualization** button ![](../../../assets/icons/sc_visual_small.png) to create an ODB file with the dehomogenization result files of SwiftComp (`*.sc.u`, `*.sc.sn`), and view the contour plots of the local fields including displacements, stresses and strains.
Therefore it is not necessary to always save the CAE and ODB files of the SG.
Different material sections can be viewed, but the material properties are not stored in the ODB file.
