# Installation


## Pre-requisites

- Abaqus
- SwiftComp


## Installation

To get started to use Abaqus-SwiftComp GUI on your local machine, you just need to simply unzip the distribution package into a folder of your own choice.
Then in this folder, click the short cut `Abaqus-SwiftComp GUI` to launch it.
To install SwiftComp you should request the code from AnalySwift and follow the instruction inside the SwiftComp release package for installation.
